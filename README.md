# SkillSignal India (Lite POC)

> **Search once. Find relevant jobs. Apply smarter. Track every application. Follow up on time.**

SkillSignal India is an AI job-search, application-preparation, and career-management web application built for job seekers in any field, any experience level (freshers to senior), and any country (starting with India: LPA, notice period, Indian cities).

## Quick Start

1. **Start Services**:
   ```powershell
   .\scripts\start-all.ps1
   ```
2. **Stop Services**:
   ```powershell
   .\scripts\stop-all.ps1
   ```
3. **Health Check**:
   - Backend API: `http://localhost:8080/api/health`
   - Frontend UI: `http://localhost:5173`
   - OpenAPI Docs: `http://localhost:8080/swagger-ui.html`
